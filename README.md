# Half Adder Simulator

A simple browser-based half adder simulator for exploring XOR and AND logic alongside one-dimensional and two-dimensional arrays.

Choose binary inputs to calculate the Sum (`A ^ B`) and Carry (`A & B`). The interface shows the `circuit[4]` memory, logic circuit, and full `truthTable[4][4]`.

To run it, open `index.html` in a web browser. The project includes `style.css` and `script.js`; `half.c` contains the reference C implementation.
