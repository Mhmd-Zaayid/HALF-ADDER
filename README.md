# Half Adder Calculator

A browser-based half adder calculator. Choose 0 or 1 for each input to calculate the Sum (`A XOR B`) and Carry (`A AND B`).

The page displays both outputs and highlights the selected input pair in the truth table. It does not include a circuit diagram.

To run it, open `index.html` in a web browser. The project includes `style.css` and `script.js`; `half.c` contains the reference C implementation.
